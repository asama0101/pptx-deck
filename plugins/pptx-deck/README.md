# pptx-deck

ビジネス上の承認文書（稟議・提案・計画）を、コンサル資料のテイストの、編集できる PowerPoint（.pptx）にする Claude Code プラグイン。Windows 専用。

導入方法・使い方は、リポジトリ直下の [README.md](../../README.md)。内部構造・コマンド・テストは [docs/development.md](../../docs/development.md)。
