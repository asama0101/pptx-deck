# HTML の書き方と描画の規準

SKILL.md の 4 章の細則。断片（`source/slides/NN-X.html`）を書く前に読む。確認用の画像（`previews`）は、この HTML を Chromium で撮ったもので、PPTX の実描画ではない。型の一覧は [components.md](components.md)。

## HTML の書き方

- 1 枚 = `<section class="slide" data-layout="…">`（1280×720px）。部品は `pp-text`・`pp-shape`・`pp-line`・`pp-image`・`pp-table`・`pp-chart`・`pp-picture` だけ。**これ以外のクラスの文字や図は PPTX に出ない**。
- 見てほしい要素（題・強調・差し替える所など、2〜4 点）には `data-note="題：結論の一文"` を付ける。レビューページが枠と番号で示す。同じ文を付けた要素は 1 つの見どころとして、枠でまとまる。PPTX には影響しない。型庫（`assets/components/`）の断片には付けてある。差し替えるときは、文が内容に合うかを見直す。
- 位置は `style="left;top;width;height"`（px）。文字には必ず幅を付ける。面と文字は兄弟要素にし、文字の中心を含む面が背景色になる。
- 文字: `data-role` = `title|lead|body|caption|display`。`title` は題（名詞句 20 字以内）、`lead` はヘッドメッセージの帯の中の文（判断を言い切る 30〜60 字。チャートタイトルは `body` で書く）。表紙・裏表紙の題と副題は `data-ph="title|subtitle"`（位置はテンプレート）。箇条書きは `<div class="pp-text"><ul><li>`。
- 色は `var(--accent)` などの変数だけ。基調色の文字は白地かつ 24px 以上のときだけ（薄い面の上の大きな数字は `num t-dark`）。**強調色（`f-emph`・`t-emph`）は 1 スライドに 1 点**（推奨・承認を求める対象）。
- 本文 14pt（約 19px）以上、注記 10pt（14px）以上。出典を書くときだけ、`data-role="caption" data-chrome` で本文領域の下端（`top:calc(var(--area-y) + var(--area-h))`。標準は y 640〜664）に置く。領域が標準より狭いテンプレートでは、出典が上がって本文と重なるので、`overlap` の指摘に従って本文の位置を直す。
- 視線誘導: 読む順は **Z の法則**（左上 → 右上 → 左下へ斜め → 右下）に従い、始点（題・結論）を左上、終点（承認を求める対象・結論）を右下まで届かせる。文の寄せ方は変えない（文は左寄せ。右寄せは数字の列だけ）。使える場面では次の 3 つも使う。**矢印効果**（矢印で読む順・因果を示す。循環は輪と矢印で回して見せ、直線の矢印だけにしない。矢印は矢じり付きで、手順・因果の図には必ず入れる）、**孤立効果**（目立たせたい 1 点だけ色・大きさを変える。強調色は 1 点）、**類同の法則**（同じ種類の要素は形・色・大きさをそろえ、違う種類は変える）。
- 画像はアイコン（`icons/<名前>-<accent|emphasis|white|gray>.svg`、`alt` と `data-role="icon"` が必須。写真は `data-role="photo"`、ロゴは `data-role="logo"`）と利用者の写真だけ。`data-role` がない画像は本文の画像として `bodyImage` で止まる。
- 重ねる図（ベン図など）は、重なる要素の両方に `data-overlap`。
- 絵（`pp-picture`）: 型に当てはまらない図（NW 構成図・トラフィックフロー・障害動作・自己紹介・画面への注釈）は、`<div class="pp-picture" data-alt="…" style="left;top;width;height"><svg viewBox="0 0 幅 高さ">…</svg></div>` と書く。`build` が絵の範囲だけを透過・3 倍の PNG にして、1 枚の画像として貼る（**絵の中身は PowerPoint で直せない**。題・ヘッドメッセージ・チャートタイトル・注釈は編集できる文字）。`data-alt`（絵の内容 1〜2 文）は必須。絵の中の色は `sv-f-*`（塗り）・`sv-s-*`（線）のクラスか `var(--…)` だけ（リテラルは警告）、文字は 14pt（約 19px）以上、強調色は 1 枚に 1 点。絵の内部の重なりは検査されない（文字どうしの重なりは警告）。絵全体とほかの部品の重なり・本文領域外は検査される。書き方・部品・図の種類ごとの作法は [picture-craft.md](picture-craft.md)。
- グラフ: `data-chart='{"type":"bar|barh|line|pie|stacked|stacked100|waterfall","categories":[…],"series":[{"name":"…","values":[…]}],"highlight":番号,"fmt":"#,##0","totals":[…],"axis":{"min":0,"max":600,"major":150}}'`。`axis`（任意）は値の軸の最小・最大・目盛の間隔を固定する。省くと自動。小グラフを並べるときは、全パネルに同じ `axis` を書く。ブラウザのプレビューは近似で、実際は PowerPoint のグラフになる。

## 配色の 3 役

配色の 3 役（面積の目安）: **ベース**＝白・パネル地（`--bg-soft`）・無彩色（文字・罫線・灰のグラフ）で面の約 70%。**メイン**＝基調色（`--accent`）とその階調（dark／soft／mid／light）で約 25%。濃い基調色は見出しの面・棒・小さな印に限り（面の縁に沿った基調色の縦線・横帯は使わない）、大きな面（三角形・円・背景の帯）は淡い階調（`f-light`・`f-soft2`・半透明 20%）にする。**アクセント**＝強調色（`--emphasis`）で 5% 以下、**1 枚 1 点**（推す案・承認点・差の値）。

## 描画の規準

- 配置の 4 原則: ①縦軸・横軸を決めてから置く（縦＝対象・分類・プレイヤー、横＝時間・工程・判断軸）。②同じ語を 1 枚に 2 度書かない。2 度出たら軸・見出しにくくり出す（軸ラベル・固有名・単位は数えない）。③1 つの図に 3 つ目の軸を持ち込まない。要るなら左右か上下に分ける。④数値の大小は、面積・長さ・太さに比例させる。
- 斜めの線: `pp-line` に `data-dir="diag"`（箱の左上→右下）または `data-dir="diag-up"`（左下→右上）を付けると、箱の対角線を引く（太さは `border-top` か 3px。矢印は `data-arrow="end"`）。拡大の関係（注目枠から拡大の画面へ広がる 2 本）など、斜めが意味を持つ図だけに使う。HTML の確認画面では箱が塗られて見えるが、PPTX では線になる。他の要素と重なるので `data-overlap` を付ける。
- 記号文法（全ページで同じ意味にする）: 実線（`pp-line`）＝実績・確定／破線（`dashed`。`pp-line`・`pp-shape` に付ける）＝予測・計画・消える要素／点線（`dotted`）＝補助輪郭。塗り＝実績・自社／枠線のみ（`f-outline`）＝計画・目標／濃色（`f-accent`・`f-dark`）＝主役、淡色＝文脈。比較では要素の位置を変えない。破線・点線は PPTX の線種になる。
- 階調: 基調色に白を 28・52・75% 混ぜた 3 段（`--accent-soft`＝`f-soft2`、`--accent-mid`＝`f-mid`、`--accent-light`＝`f-light`）。基調色を `#RRGGBB` で指定しても同じ式で作る。パネル地は `--bg-soft`（`f-soft`）、罫線は `--line`（`hr`）。
- グラフの作法: 軸は 0 始まり（％・指数は例外）。目盛は 3〜6。単位は図の左上に 1 回。全要素に実数ラベル（`data-chart` は自動で付く）。目盛線は出さない（自動で消える）。凡例を離れた場所に置かない（系列は 3 本まで。複数系列の凡例はグラフの直下に付く）。複数のグラフを並べるときは `axis` で軸をそろえる。実績と予測の境界は図中に示す。チャートタイトル（`data-role="body"` の太字。`lead` はヘッドメッセージの帯に使う）は名詞句で、時点と単位を含める。1 枚に図を 2 つ以上置くときは、図ごとにチャートタイトルを図の真上に置く。
- 表: 列幅は最長のセルで決め、語の途中で折り返さない。空のセルは空欄か「なし」（ダッシュで埋めない）。
- 本体は、本文領域の下端近くまで使い切る。無所属の空白帯を残さない。
- 禁止: 多色グラデ・3D・角丸の多用（`.r` は 2px）・全幅のカラーバー・署名・ダッシュ（—。題・本文・表・注記のどこにも使わない）。アイコンは使えるが、飾りにせず、ラベルを添える。
