# 部品の必要・不要の整理（PDF 39 のアイデアとの突き合わせ）

作成: 2026-10-13 · 状態: 利用者の判定待ち · 対応はPDFの見出しと部品名からの私の推定（形の一致までは見ていない行は「近い」と書く）

## 判定の記入方法

右端の「判定」列に、**要る／不要／作り直し／新規** のどれかを書いてください。PDFのパターンで「なし」の行は、新規に作るかどうかの判定です。

## 利用者がすでに伝えた判定（2026-10-13）

| 部品 | 判定 | 確認したいこと |
|---|---|---|
| track-record・quote-phrase・mvv・members・company・case | 不要 | **部品ごと削除**（デザイン1・2・3の全部）でよいか。今は「d2・d3 だけ不要」とも読めるため、削除前に確認 |
| screenshot の d2・d3 | 作り直し | 作り直す方向（下の「キャプチャ」3行を参照） |
